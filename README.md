# Ankit Singh - Portfolio

Static portfolio and résumé site for Ankit Singh, backend engineer. Plain HTML, CSS and JS with vendored GSAP and self-hosted fonts, so there is no build step.

Run locally with `python3 -m http.server 4640` and open http://localhost:4640. Deploy on Vercel by importing this repo, choosing framework preset "Other", leaving the build command empty and setting the output directory to `.`.
